# Análisis de ventas de videojuegos

## Descripción
Proyecto de análisis de datos enfocado en identificar patrones de éxito en videojuegos a partir de datos históricos de ventas, plataformas, géneros y clasificaciones ESRB.

## Objetivo
Analizar el comportamiento de las ventas por región y plataforma para apoyar la planificación de campañas publicitarias basadas en datos.

## Herramientas utilizadas
- Python
- pandas
- NumPy
- SciPy
- matplotlib
- seaborn
- Jupyter Notebook

## Resultados principales
- Identificación de plataformas y géneros con mayor potencial de ventas.
- Análisis del impacto de reseñas y clasificaciones en el desempeño comercial.
- Validación de hipótesis mediante pruebas estadísticas.
